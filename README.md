# Heartbeat Animation | Love in Code

This small project was inspired by the drama series *「點燃我，溫暖你。」*, where I saw a scene with a beating heart animation that deeply touched me. After watching the show, I began searching for ways to simulate this heart-beating effect through code. On TikTok, I came across a similar animation, which, while not exactly the same, was very close to what I needed.

The code for this project was created by carefully studying, screenshotting, modifying, and annotating the original code until I achieved the heart-beating animation that matches the one from the drama. Although I can no longer remember the original contributor of this code, I would like to express my sincere gratitude to them for helping me understand how the heart animation works.

## 🛠️ Tech Stack

- **Python**
- **PyQt5** (used for the graphical interface and heart animation effects)
- **Mathematics and Random Number Generation** (to control the heart’s beating and color changes)

## 📦 Features

1. **Dynamic Rendering**: Utilizes PyQt5's drawing tools to create dynamic rendering of the heart, scaling and beating according to the passage of time.

## 🚀 How to Run

1. Install the required libraries:
    ```bash
    pip install PyQt5
    ```

2. Run the program:
    ```bash
    python main.py
    ```

3. If everything works correctly, a window will pop up displaying the beating heart animation.
